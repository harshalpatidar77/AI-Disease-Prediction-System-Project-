# AI Disease Prediction System 

An end-to-end machine learning project that predicts disease categories from healthcare-related symptoms and patient features.

## Features

- Dataset generation and analysis
- Exploratory Data Analysis
- Missing-value handling
- Duplicate handling
- Feature engineering
- Multiple ML algorithms
- Cross-validation
- Model comparison
- Hyperparameter tuning
- Confusion matrix
- Precision
- Recall
- F1-score
- Prediction probability
- Feature analysis
- Model serialization
- Streamlit interface

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Gradient Boosting

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Streamlit

## Project Workflow

Dataset
→ EDA
→ Data Cleaning
→ Feature Engineering
→ Preprocessing
→ Model Training
→ Cross Validation
→ Model Comparison
→ Hyperparameter Tuning
→ Best Model
→ Streamlit Prediction
